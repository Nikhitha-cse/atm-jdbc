# ATM Management System using Java and JDBC

A Java-based console application that simulates core Automated Teller Machine (ATM) operations using Java Database Connectivity (JDBC) to connect with a MySQL database.

## Features
* User Authentication (Account Number & PIN verification)
* Balance Inquiry
* Cash Deposit & Withdrawal
* Transaction History / Statement Generation

## Tech Stack
* **Language:** Java
* **Database:** MySQL
* **Build Tool:** Maven
* **Database Driver:** JDBC (MySQL Connector/J)
